## 📖 核心方法论：四层原子化金字塔

90% 的团队给智能客服喂几十万字说明书会彻底翻车，是因为传统文档充满长段落、新旧政策冲突、且缺乏口语桥接。

**四层原子化拆解方案**：
1. **[表 1：基础政策规矩表](markdown-preview/01_basic_policies.md)**（底线红线）：质保期多久、退换货运费谁出、全店唯一权威版本，绝不含糊。
2. **[表 2：产品参数原子表](markdown-preview/02_product_specs.md)**（事实真理）：将零散长段落转为结构化表格（尺寸/电压/适配机型/故障排查），彻底消除参数幻觉。
3. **[表 3：买家大白话扩展表](markdown-preview/03_colloquial_synonyms.md)**（语义桥接）：官方写“设备无法开机”，买家提问全是“灯不亮/没反应/死机了”，每条补充 3-5 句大白话。
4. **[表 4：决策与行动指令表](markdown-preview/04_action_triggers.md)**（动作闭环）：连带后台动作（索要凭证、自动建补发工单、小额补偿），告别复读机。
