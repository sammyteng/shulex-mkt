## 💡 每个子项目标准结构规范

每个引流子项目均采用标准化结构，确保无论是普通人类用户还是 AI Agent 都能即取即用：

```text
projects/
└── {编号}-{主题英文名}/
    ├── README.md               # 本期引流主题长图文/背景与双版本导览
    ├── excel/                  # 📊 人工实操版：包含填好的 .xlsx 范例与填表指南
    ├── skill/                  # 🤖 AI Agent 版：包含 SKILL.md、大模型 Prompt、Python 自动化脚本
    └── markdown-preview/       # 📄 网页预览版：免下载直接在 GitHub 查阅所有排版表格
```

## 🔗 如何在社媒引流中分发？

* **发给普通运营/店长**：直接给他们发对应子项目的 `excel/` 目录或 `.xlsx` 下载链接；
* **发给 AI 工程师/大模型用户**：直接给他们发对应子项目的 `skill/SKILL.md` 链接，对方可直接作为技能导入 Claude Code、Antigravity、Cursor 或 Dify。
